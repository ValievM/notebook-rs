# notebook-rs

Исследовательский блокнот в духе NotebookLM на Rust: ваши источники, сильная модель (Codex по подписке) и **проверенные цитаты**. Если модель привела цитату, которой нет в источнике, она отбрасывается и это видно.

## Что уже есть (срез 1)

- `nb add <блокнот> <файл>`: источник (txt/md) режется на фрагменты и индексируется в SQLite (FTS5, BM25); повторная загрузка того же названия заменяет источник, копий нет.
- `nb ask <блокнот> "вопрос"`: ищет фрагменты только в этом блокноте, просит Codex отвечать по ним в JSON и проверяет каждую цитату по тексту.
- Модель за трейтом `Llm`: сейчас `codex exec` (вход по подписке делаете вы сами через `codex login`, токены программа не видит).

```bash
cargo test
cargo run -- add Аренда договор.txt
cargo run -- ask Аренда "За сколько дней предупредить о расторжении?"
```

## План

1. Эмбеддинги локально (fastembed) и поиск по смыслу вместе с BM25.
2. Источники: PDF, веб-страницы.
3. Окно на Tauri: блокноты, источники, чат, переход по цитате к месту в источнике.
4. Свои надстройки: режимы «конспект», «сравнить источники», «план по материалам», карточки для повторения.
5. Мост «OpenAI-совместимый адрес поверх `codex exec`», чтобы другие программы могли пользоваться подпиской.

Образец функций: [Open Notebook](https://github.com/lfnovo/open-notebook) (MIT). Код оттуда не копируется.
