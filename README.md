# notebook-rs

Исследовательский блокнот в духе NotebookLM на Rust: ваши источники, сильная модель (Codex по подписке) и **проверенные цитаты**. Если модель привела цитату, которой нет в источнике, она отбрасывается и это видно.

## Что уже есть (срез 1)

- `nb add <блокнот> <файл | pdf | http(s)-адрес>`: источник (txt/md, PDF с текстом, веб-страница) режется по заголовкам на фрагменты и индексируется в SQLite (FTS5 BM25 и векторы); повторная загрузка того же названия заменяет источник, копий нет.
- `nb ask <блокнот> "вопрос"`: ищет фрагменты только в этом блокноте (BM25 и векторы, объединённые через RRF), просит Codex отвечать по ним в JSON и проверяет каждую цитату по тексту.
- Модель за трейтом `Llm`: сейчас `codex exec` (вход по подписке делаете вы сами через `codex login`, токены программа не видит).

```bash
cargo test
cargo run -- add Аренда договор.txt
cargo run -- add Аренда скан-с-текстом.pdf
cargo run -- add Аренда https://example.com/page
cargo run -- ask --deep Аренда "Срок, оплата и условия выезда?"
cargo run -- summarize Аренда
cargo run -- compare Аренда договор.txt памятка.pdf
cargo run -- ask Аренда "За сколько дней предупредить о расторжении?"
```

## Окно

```bash
cargo run -p notebook-rs-app
```

Блокноты и источники те же, что у командной строки (`~/.notebook-rs/`). При первом запуске скачивается модель поиска (около 130 МБ), окно покажет баннер; окно занимает около 1 ГБ памяти. Для ответов нужен вход в Codex (`codex login`). Вёрстку можно посмотреть без приложения: `cd ui && python3 -m http.server 8765`, затем `http://127.0.0.1:8765` (покажет тестовые данные).

## Вход через ChatGPT (ответы по вашей подписке)

```bash
cargo run -- login      # откроет браузер: войдите и разрешите использовать план ChatGPT
cargo run -- account    # вошли ли вы и кто отвечает
cargo run -- logout     # забыть вход на этом компьютере
```

Вошли: отвечает ChatGPT по вашей подписке (расходуется лимит тарифа; приложение появится в настройках ChatGPT отдельной строкой). Не вошли: отвечает Codex (`codex login`). В окне то же самое кнопкой слева. Файл входа: `~/.notebook-rs/chatgpt-auth.json` (права только владельцу).

Модель и «сила мышления» (по умолчанию первая модель вашего аккаунта): список `nb models`, выбор навсегда `nb use gpt-6-luna --effort medium` (файл `~/.notebook-rs/settings.json`) или два списка «Модель» и «Размышление» в окне под кнопкой входа; выбор действует со следующего вопроса, перезапуск не нужен; разово `--model <имя>` / `--effort low|medium|high` или переменные `NOTEBOOK_RS_MODEL`, `NOTEBOOK_RS_EFFORT` (их читает и окно). Какая модель отвечала, видно в `nb stats`.

## Метрики

Программа записывает, сколько длилась каждая операция и чем кончилась (файл `~/.notebook-rs/metrics.db`, хранится 30 дней): время, размеры, названия источников, текст ошибки, память процесса. Тексты источников, вопросы и ответы не записываются.

```bash
cargo run -- stats --hours 24    # операции, ошибки, память, самые медленные
cargo run -- --no-metrics ask …  # не записывать
```

В окне то же самое: кнопка «Метрики» слева внизу.

## Документы проекта

`AGENTS.md` (правила и вход для новой сессии) → `docs/PROJECT.md` (что и зачем) → `docs/ROADMAP.md` (что сделано и что дальше) → `docs/ARCHITECTURE.md` (слои и паттерны) → `docs/DECISIONS.md` (почему так).

Образец функций: [Open Notebook](https://github.com/lfnovo/open-notebook) (MIT). Код оттуда не копируется.

## Если раньше стояла полная модель

Версия до 2026-10-25 использовала полную модель (465 МБ, до 3,8 ГБ памяти). Её можно удалить, а источники, добавленные тогда, нужно добавить заново (векторы разных моделей не смешиваются):

```bash
rm -r ~/.notebook-rs/models/models--intfloat--multilingual-e5-small
```
