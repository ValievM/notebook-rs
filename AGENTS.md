# AGENTS.md

notebook-rs: исследовательский блокнот в духе NotebookLM на Rust. Свои источники, сильная модель, ответы с **проверенными цитатами**.

## Начни отсюда (новая сессия)
1. `docs/PROJECT.md`: что это, зачем, где мы сейчас, как продолжить.
2. `docs/ROADMAP.md`: что сделано, что дальше, что в перспективе.
3. `docs/ARCHITECTURE.md`: слои, трейты, паттерны. Перед правкой кода.
4. `docs/DECISIONS.md`: почему выбрано так (и что сравнивали). Не переигрывай решение молча.

Документ важнее памяти. Решение изменилось: обнови документ в том же коммите. В конце работы обнови статус в `docs/ROADMAP.md`.

## Правила
- Владелец начинающий Backend/DevOps: объясняй просто, сначала суть. Общение по-русски; код, имена, комментарии на английском; пользовательские тексты русские.
- Спрашивай перед: новой зависимостью (кроме уже записанных в DECISIONS), отступлением от ARCHITECTURE, скачиванием моделей и больших файлов.
- Токены и ключи только в системном хранилище/через `codex login`; в репозитории, логах и тестах их нет.
- Код: трейт на границе (модель, эмбеддинги, поиск, хранилище), конкретная реализация за ним; SQL только в `store.rs`; ошибки через `error::Error`, `anyhow` только в `main.rs`.
- Тесты без сети и без настоящей модели: фейки через трейты. Логика через красный тест; тест с логикой доказывай мутацией.

## Команды
```
cargo fmt && cargo clippy --all-targets && cargo test
cargo run -- add <блокнот> <файл>
cargo run -- ask <блокнот> "вопрос"
```
Готово, когда: fmt, clippy без предупреждений, все тесты зелёные, документы обновлены.
